# MalWeave

MalWeave contains the dataset audit, extraction, training and evaluation code.
The current paper design and open research decisions are maintained outside
this repository.

- [Research overview](workflows/research-protocol.md) maps the current study to the implementation.
- [Data preparation](workflows/data-preparation.md) covers the four audited datasets.
- [RanDS checkpoint experiments](workflows/lmlm-checkpoints.md) documents the earlier A/C/E1/E2 runs.
- The [RanDS scratch baseline](workflows/rands-scratch.md) is paused.

For development, read [getting started](getting-started.md),
[project structure](project-structure.md) and [environment](development/environment.md).
Use the [dataset catalog](datasets/index.md) for source-specific facts.
